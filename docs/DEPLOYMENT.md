# Phone interview demo

Live URL: https://oneday-begin.github.io/Rocket-Landing-Lab/

Hosting: GitHub Pages, free on the public Oneday-begin/Rocket-Landing-Lab repository. Pages source: gh-pages branch, root folder. The main branch remains the Python project.

Open the live link on your phone with internet access. Your laptop can be switched off. Add it to your home screen or bookmark it. During a demonstration, enter the lab, filter weather, replay a flight, inspect the predictor matrix, search evidence, then show the broader-weather results and PDF.

This is a read-only export of genuine saved simulation evidence: 720 complete 50 Hz flight histories, original scores, precomputed forecasts from the fitted classifier, measured test reports, and GIF recordings. It performs filtering, statistics, CSV export and evidence search in your browser. The hosted assistant is labeled evidence search and does not run Ollama. New simulation, training and local language generation remain in Open-Web-Lab.cmd on the laptop.

To update: regenerate with tools/build_phone_demo.py using the project Python environment, review the output site directory, and publish it to gh-pages. The exporter and its browser adapter are saved in tools/. Keep the report PDF and recorded evidence consistent with the measurements you publish. No API keys are embedded in the demo.
